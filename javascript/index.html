2. JavaScript Values: Literals vs. Variables

Literals are fixed values (numbers like 10.50, strings in quotes). Variables store changing values.

3. Keywords are Case-Sensitive Box

JavaScript keywords must be lowercase. Using LET or Let causes a crash.

let normalVar = "Valid keyword"; try { eval("LET brokenVar = 10;"); } catch(err) { // Catches crash }

Rules: Start with a letter, _, or $. No reserved words like const as names.

7. Casing Conventions (Camel Case)

Hyphens like first-name are banned (read as subtraction). Standard practice is lower Camel Case.
